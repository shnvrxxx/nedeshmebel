# 🪑 Мебельная фирма «Недешёвая мебель»

Одностраничный сайт-визитка для ателье дорогой мебели.  
Сайт полностью адаптивный, имеет тёмную тему, слайдер работ, карусель отзывов и интеграцию с Telegram-ботом для сбора заявок.

## 🔗 Ссылки

- 🎯 [Живой сайт](https://shnvrxxx.github.io/nedeshmebel/) 
- 🤖 [Telegram-бот](https://t.me/NedeshMebel_bot) — для консультаций и заказов

## 🛠 Технологии

- HTML5
- CSS3 (адаптив, CSS-переменные для тёмной темы)
- JavaScript (слайдеры, Intersection Observer, анимации)
- Google Fonts (Montserrat)
- Font Awesome 6 (иконки)
